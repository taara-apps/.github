# Security Policy

## Reporting a problem

If you find a security problem in a Taara app, please don't open a public issue. Email [taara-apps@proton.me](mailto:taara-apps@proton.me) with:

- which app and version,
- what the problem is and how to reproduce it,
- what someone could do with it.

You'll get a reply within a week. Once a fix is released, you'll be credited in the release notes unless you'd rather not be.

## Supported versions

Only the latest release of each app receives security fixes.
