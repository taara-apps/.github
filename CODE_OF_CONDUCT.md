# Code of Conduct

Taara follows the [GNOME Code of Conduct](https://conduct.gnome.org/).

In short: be friendly and patient, be welcoming, be respectful, and assume good intentions. Harassment and exclusionary behaviour aren't accepted in any Taara space, including issues, pull requests and discussions.

To report a problem, email [taara-apps@proton.me](mailto:taara-apps@proton.me). Reports are kept private.
